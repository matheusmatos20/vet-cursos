# Frontend Clinvet

Cada página possui arquivos próprios **HTML, CSS e JS**. Recursos compartilhados ficam em `frontend/shared/`.

Páginas migradas: index, aluno, coordenador, gestao, chamada, frequencia, notas, feedback, painel, material, ranking e checkin.

Os arquivos da raiz foram preservados temporariamente para manter o deploy atual do Cloudflare enquanto a integração com o backend FastAPI é concluída.
